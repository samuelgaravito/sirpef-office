# Fuentes de la app

La app incluye dos familias con licencia **SIL Open Font License 1.1**:

| Fuente | Uso | Origen |
| --- | --- | --- |
| **Source Sans 3** | Interfaz de SirpefOffice | [Adobe Source Sans](https://github.com/adobe-fonts/source-sans) |
| **Caveat** | Firma tipográfica | [Google Fonts · Caveat](https://fonts.google.com/specimen/Caveat) |

Archivos:

```text
app/src/main/res/font/source_sans_3_regular.ttf
app/src/main/res/font/source_sans_3_medium.ttf
app/src/main/res/font/source_sans_3_semibold.ttf
app/src/main/res/font/source_sans_3_bold.ttf
app/src/main/res/font/source_sans_3_black.ttf
app/src/main/res/font/caveat.ttf
```

La licencia OFL permite usar, modificar y redistribuir las fuentes manteniendo
el aviso de copyright. No se modificaron los archivos originales.
